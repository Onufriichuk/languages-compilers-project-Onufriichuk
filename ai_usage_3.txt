**4. What I Understood**

The for loop repeats the code for values within a given integer range. The compiler creates LLVM blocks to check the condition, execute the loop body, increase the counter, and exit the loop. Break allows the loop to stop early.

The optimizer works on the AST before generating LLVM IR. It removes unused variables and functions and replaces some single-use function calls with their bodies. This reduces unnecessary code while keeping the program output the same.

Savings Planner uses the new for loop to read several deposits. A structure and its member function store and update the total, and another function calculates the doubled savings goal.
