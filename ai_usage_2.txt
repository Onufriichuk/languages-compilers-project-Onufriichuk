## 3. My Understanding

The normalization step converts my language syntax into the format understood by the reused compiler backend.

The semantic analyzer checks types, function arguments, variable scopes, and mutability before generating LLVM IR.

LLVM IRBuilder generates instructions for variables, arithmetic, functions, and control flow. Structures use GEP to access fields by index, while member functions receive a pointer to their object.

Input and output use `scanf` and `printf`, which are linked through Clang.
